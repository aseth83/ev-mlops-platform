# EV MLOps Platform

End-to-end EV energy consumption prediction platform built while learning ML engineering, MLOps, and AI engineering.

## Project Goal

The goal of this project is to build and understand the complete lifecycle of a machine learning system, including:

* data ingestion
* data validation
* feature engineering
* model training
* model evaluation
* experiment tracking
* model versioning
* API inference
* testing
* Docker
* CI/CD
* workflow orchestration
* Kubernetes
* monitoring
* drift detection
* retraining
* rollback
* cloud architecture
